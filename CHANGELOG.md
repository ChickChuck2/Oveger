# Changelog

## [1.1.0] - 2026-05-04
### Fixed
- Bug in group lookup that caused items to not show in their groups.
- Limitation that allowed only one group per item.

### Added
- Multi-group support: items can now belong to multiple categories.
- Context-aware group removal from the right-click menu.
- Initial architectural documentation in `/docs`.
- Silent startup support via `--minimized` flag.
- Increased process priority to `High` for improved responsiveness.
